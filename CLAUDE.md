# PlayFieldPortal

## Local Android SDK tools

On this PC, Android SDK platform-tools are installed at:

```text
C:\Users\johnn\AppData\Local\Android\Sdk\platform-tools\adb.exe
```

Use that path when `adb` is not available on PATH. For example:

```bash
"C:\Users\johnn\AppData\Local\Android\Sdk\platform-tools\adb.exe" devices
```
