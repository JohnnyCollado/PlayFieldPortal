# UI survey — 2026-11-19

Live walk-through of PFP on the AYN Odin 3, driven with an Xbox controller, from the "Drill-down"
session. Originally given only as a chat reply (19 Nov 2026, 21:37); saved here on 20 Nov 2026 from
that session's transcript, unchanged except for formatting.

**Status of each item since then is not re-checked.** In the same session the Settings scaffold
mock-up (below) was approved and built, and later work changed the root-folder rows; nothing else
here has been confirmed fixed.

## Summary

The XMB itself is the strongest part of the app and needs no revision; most of what needs work sits
in the shared Settings scaffold, so a handful of fixes there would improve about 30 screens at once.
The survey is partial: what was not reached is listed at the end.

## Verdict per shared element

| Element | Needs revision? | Main reason |
|---|---|---|
| XMB cross, category bar, wave, status strip | No, one fix | Status strip is unreadable over game art |
| Settings scaffold and rows | Yes, highest value | Focus contrast, empty footer, clipped rows, option lists in sublabels |
| Settings section sub-lists | Yes | Every item is the same wrench; section name is never shown |
| Setup wizard | Yes, light | Same scaffold issues plus repeated copy |
| Context menu | Yes | Art bleeds through; red on blue; no scroll cue |
| Modals and keyboard | Light | Prompt chip collides with the dialog; small touch keys |
| Notification panel and results sheet | Light | Mostly copy |
| Game detail | Yes, as a style call | A different visual language from the rest |
| App drawer | Light | Weak focus ring |

## Settings scaffold (32 screens)

- **Focused row loses its sublabel.** The highlight is pale and the second line is pale, so the line
  you most need is the hardest to read. Trailing items do the same: "PFP Default" and the play button
  on Boot Video and Navigation almost vanish on focus. Darken the highlight or switch focused text to
  full white.
- **The footer band is empty but still clips content.** On every Settings screen the bottom strip
  shows no prompts, yet rows and group headers are cut at its edge (Library Manager, Display, System
  Update). Player Status and the game detail show prompts in the same band. Either show the prompts
  there or give the space back to the list.
- **Sublabels are used as option menus.** Display lists every choice separated by pipes ("Animated |
  Reduced (dimmer, calmer) | Static (frozen) | …"). Icon Legibility wraps to two lines and is
  clipped. The sublabel should describe the current value; the choices belong in the picker.
- **Sliders read backwards.** The filled part is black and the empty part is blue, so Sound at 100%
  looks like a dead bar.
- **On/off is shown two ways.** Display uses switches; Controller shows the text "Off" for the same
  kind of setting.
- **Headers and grouping.** Controller has a group header, a description and a row all saying
  "A / B Swap". Wave Style sits under "Lock Screen". Group headers and the breadcrumb are tracked
  capitals, and the breadcrumb says "Settings", "Emulators" or "Library Manager" with no clear rule.
- **Destructive rows look like any other.** "Re-Scrape All Games" and "Reset Emulator Configuration"
  have no warning treatment. Emulator › Installed opened with the cursor already on the reset row;
  seen once, cause not checked.

## Copy and naming

- **Names change between menu and screen:** "Hidden Games" opens "Hidden Items"; "Windows Games"
  opens "Windows Memory Card".
- **Internal terms reach the user:** package names with `ACTION_VIEW` / `COMPONENT`, "ROM root",
  "ROM/app files", "Consoles home under this root".
- **Touch wording on the pad:** "Tap to dismiss", "(tap to replace)".
- **Mixed formats:** "Checked Nov 19, 16:17" on System Update against "4:17 PM" on Logs and the
  status strip; Title Case and sentence case mixed on the same screen.
- **Advice that contradicts itself:** the results sheet says the fix is to pick the PS3 folder, then
  "What you can do: Try the update again later."

## Other elements

- **Settings sub-lists:** all six sections and every item share one wrench icon, and once inside a
  section its name isn't shown anywhere. Distinct glyphs per section would fix both.
- **Context menu:** the game logo shows through the menu behind "Favorite"; "Remove from Library"
  and "Clear All" are red on mid-blue; the title sits on the screen edge; the list runs off the
  bottom with no cue. The same game has two different menus (XMB list and detail screen) with
  different names and group order.
- **Game list over art:** date, time and "Filter: Title" sit directly on busy artwork. A soft
  gradient behind the strip would fix it.
- **Game detail:** rounded cards, icon pill buttons and a bright green Launch button appear nowhere
  else. The header reads "PlayStation Portable / ROM" where the game's name should be, and "ROM"
  appears twice.
- **Surfaces:** five panel styles (blue translucent panel, blue menu slab, charcoal sheet with amber
  edge, charcoal dialog, detail cards). Settle on two.
- **Confirm dialog:** focus defaults to Cancel, which is right, but the prompt chip overlaps the
  dialog's bottom edge.
- **Keyboard:** fine on the pad; keys are about 36dp, small for touch.
- **Wizard:** no step total, "Welcome to Play Field Portal" twice on step 1, and "Rescan" offered
  before any folder exists.
- **App drawer:** clean grid, but the focus ring is a thin square that's easy to lose.

## Not covered

- **Not visited:** music, video and photo players; the HSV colour and custom-icon pickers; layout
  adjust; Artwork Studio; search online; the boot and Game Boot animations; touch mode; wizard steps
  after 7; about 15 Settings sub-screens (Media, About, Credits, Notifications, Custom Emulators,
  Windows and Artwork import among them).
- **Mis-step during the walk:** one dropped button press opened Chrome from the Network column; its
  menu was closed without activating anything.
- **App drawer shortcut:** Back at the top of the XMB opened the app drawer. Not confirmed whether
  that's intended.

## Follow-up in the same session

The Settings scaffold mock-up was approved (19 Nov, 22:49): a dark focused band with a white leading
bar; footer prompts including a bumper "Next group" jump; sublabels that describe the current value
with the choices in the picker; a white-filled slider; warning glyph and coral label on destructive
rows; sentence-case group headers; a path-style breadcrumb ("Settings › Display").
