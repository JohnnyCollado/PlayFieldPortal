Decisions

Decided

  • Flat tabs.All eleven categories stay one press apart. The grouped variant was dropped.
  • This mockup is the target layout.The Thor's 833 × 468 dp is the reference canvas.
  • Larger and longer screens get more results, not bigger chrome.Bands keep their dp heights and type never scales; all extra width and height becomes more grid columns and rows. The capacity rules and worked examples are in the C16 plan.

Still open

  • Touch targets.These rows are 22–28 dp, which suits a controller. They sit below the 48 dp touch minimum, so the touch mode in C16 task 4.3 would need to grow them.
  • Phase 5's panels.The saved-screenshots panel, per-tile checkboxes and apply bar from the earlier PNG mockup are not placed in this layout yet.
